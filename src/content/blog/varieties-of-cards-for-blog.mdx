Looking for creative ways to showcase content in your blog posts? Our custom card components make it easy to present information in a visually appealing, organized manner. Let's explore the Notebook Card component – a beautiful way to display content with a unique paper-like aesthetic.

## What are Notebook Cards?

Notebook Cards are React components that mimic the appearance of a physical notebook page, complete with:
- **Lined paper effect** - Horizontal blue lines for that classic notebook look
- **Vertical margin line** - Red left margin just like real notebooks
- **Binding holes** - Circular cutouts on the left side
- **Tape effect** - Decorative tape elements at top and bottom
- **Automatic dark mode** - Seamlessly adapts to your theme
- **Responsive grid layout** - Works perfectly on all screen sizes

## 📦 Importing the Components

To use Notebook Cards in your MDX files, import both the card and container components:

```jsx
import { NotebookCard, NotebookCardContainer } from '@/react/Cards';
```

**Alternative import with relative path:**

```jsx
import { NotebookCard, NotebookCardContainer } from "../../react/Cards";
```

> **Important:** Always use the `.mdx` file extension (not `.md`) when working with React components in your blog posts.

## 📋 Component Props

### NotebookCardContainer

The container creates a responsive grid layout for multiple cards.

| Prop | Type | Description |
|------|------|-------------|
| `children` | ReactNode | NotebookCard components to display |

### NotebookCard

Individual card component with notebook styling.

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `image` | string | Yes | - | URL or path to the image |
| `title` | string | Yes | - | Card heading/title |
| `imageAlt` | string | No | `title` value | Alt text for accessibility |
| `children` | ReactNode | Yes | - | Card content (paragraphs, HTML, etc.) |

## ✨ Key Features

- **Responsive Design**: Automatically adjusts to screen size with grid auto-fit
- **Dark Mode Support**: Seamlessly switches colors based on your theme
- **Accessibility**: Proper alt text support for images
- **Flexible Content**: Accepts any valid JSX/HTML in the content area
- **Monospace Font**: Classic notebook aesthetic with monospace typography
- **No CSS Conflicts**: Uses inline styles following best practices

## 💡 Use Cases

Notebook Cards are perfect for:
- **Product showcases** - Display items with images and descriptions
- **Recipe collections** - Share cooking recipes with beautiful photos
- **Portfolio pieces** - Highlight your work with project cards
- **Team members** - Introduce your team with profile cards
- **Resource listings** - Curate tools, books, or articles
- **Tutorial steps** - Break down complex processes visually
